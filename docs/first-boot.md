# First Boot

On first conversation, the agent follows the `BORN.md` protocol.

## What Happens

1. The LLM reads `SOUL.md` to understand its personality.
2. It greets the user with 1-3 sentences.
3. It asks:
   - "What name would you like to give me?"
   - "What language do you prefer?"
   - "What would you like to do?"

## Customizing

Edit `SOUL.md` to change the agent's personality before first boot.

The agent will write the chosen name into `SOUL.md` and `MEMORY.md`.
